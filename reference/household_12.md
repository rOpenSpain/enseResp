# household_12

Household survey of the ENSE 2011/12.

## Usage

``` r
household_12
```

## Format

A data frame with 55806 rows and 66 variables:

- `CCAA`:

  autonomous community code

- `IDENTHOGAR`:

  household identifier

- `ESTRATO`:

  sampling stratum

- `SEXO_i`:

  sex of the reference person

- `EDAD_i`:

  age of the reference person

- `NORDEN_Ai`:

  order number of the adult reference person

- `NORDEN_Mi`:

  order number of the minor reference person

- `NADULTOS`:

  number of adults in the household

- `NMENORES`:
