# children_12_labels

Provides labels to the values of the household survey. ENSE 11/12

## Usage

``` r
children_12_labels
```

## Format

A data frame with 1289 rows and 3 variables:

- `valores_ine`:

  values in survey

- `valores`:

  labels of values

- `variable_ine`:

  name of the variable
