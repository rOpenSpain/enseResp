# adults_19_labels

Provides labels to the values of the adults survey. ENSE 17/19

## Usage

``` r
adults_19_labels
```

## Format

A data frame with 2305 rows and 3 variables:

- `valores_ine`:

  values of the variable

- `valores`:

  labels

- `variable_ine`:

  name of the variable
