# children_19_labels

Provides labels to the values of the children survey. ENSE 2017/19

## Usage

``` r
children_19_labels
```

## Format

A data frame with 1310 rows and 3 variables:

- `valores_ine`:

  values of the variable

- `valores`:

  labels

- `variable_ine`:

  name of the variable
