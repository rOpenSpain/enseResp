# adults_19_info

Design of the survey. Variable characteristics of adult survey ENSE
2017/19.

## Usage

``` r
adults_19_info
```

## Format

A data frame with 455 rows and 6 variables:

- `variable_ine`:

  variable name

- `longitud`:

  field length

- `posicion_inicio`:

  start position in fixed-width file

- `posicion_final`:

  end position in fixed-width file

- `descripcion_del_campo`:

  variable description

- `tipo_variable`:

  thematic category of the variable
