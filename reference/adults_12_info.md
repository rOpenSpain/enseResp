# adults_12_info

Design of the survey. Variable characteristics of adult survey ENSE
2011/12.

## Usage

``` r
adults_12_info
```

## Format

A data frame with 577 rows and 6 variables:

- `campo`:

  variable name

- `longitud`:

  field length

- `posicion_inicio`:

  start position in fixed-width file

- `posicion_final`:

  end position in fixed-width file

- `descripcion_del_campo`:

  variable description

- `tipo_variable`:

  thematic category of the variable
