# Replace coded values with labels

Replace coded values with labels

## Usage

``` r
label_data(df, labels, vars = NULL)
```

## Arguments

- df:

  A data frame.

- labels:

  A labels data frame with columns \`valores_ine\`, \`valores\`, and
  \`variable_ine\`.

- vars:

  Optional character vector of variables to label.

## Value

A data frame with selected variables labelled.
