# adults_06_info

Design of the survey. Variable characteristics of adult survey ENSE
2006/07.

## Usage

``` r
adults_06_info
```

## Format

A data frame with 619 rows and 6 variables:

- `campo`:

  variable name

- `longitud`:

  field length

- `posicion_inicio`:

  start position in fixed-width file

- `posicion_final`:

  end position in fixed-width file

- `descripcion_del_campo`:

  variable description

- `valores_validos`:

  valid values for the variable
